## Long description (English, 2–3 paragraphs)

```
Phalanx Toolkit is the all-in-one no-code tokenization platform on TON from PLX Foundation — deploy Jettons with 10+ audited Tolk templates or a custom smart contract drafted by PLX-86 AI, then manage everything from one integrated dashboard. Every standard path uses the same audited JettonMinter / JettonWallet / TeamVesting stack (60/60 Acton tests, TEP-74/64) that powers the live PLX reference token on mainnet — audit-first by design, not a fork-and-pray deploy.

Rehearse for $0 on TON testnet (free sandbox deploy), customize metadata, connect Tonkeeper via TonConnect, and promote to mainnet when ready. Pay toolkit tiers with PLX for 50% off; 50% of PLX received is burned on receipt. Inside Telegram, PLX App adds Formation earn quests, LP & staking tools, holder growth charts, activity feeds, growth hub checklists, Ston.fi LP metrics, PLX-86 co-pilot, referrals, and launchpool campaigns — deploy, analytics, and growth in one place.

Open @phalanxfoundationbot → Phalanx Toolkit, or app.plx.foundation. Website: plx.foundation · Contracts: github.com/phalanx-foundation/plx-token · Channel: t.me/phalanxfoundation.
```

## Category

Daftar opsi platform (ton.app / tApps-style):

| Opsi | Cocok? |
|------|--------|
| **Launchpads** | **Ya — pilih ini.** Peer group-nya platform peluncuran token (GasPump, Tonstarter, launchpad DEX) — sama seperti PLX: user datang untuk meluncurkan jetton + launchpool/LP |
| Dev Tools | Alternatif kedua. Peer group-nya infra developer (TonAPI, TonConsole, TON VPN, explorer/verifier tooling) — PLX bukan API/infra, jadi kurang pas dan berisiko "salah rak" |
| Utilities | Fallback generik jika dua di atas ditolak |
| Smart Contract Audit | Tidak — kita deploy audited contracts, bukan layanan audit pihak ketiga |
| Staking | Tidak — staking hanya salah satu fitur |
| Exchanges / Bridges / Explorers / Wallets / NFT / RWA | Tidak |

**Primary:**

```
Launchpads
```

**Fallback:**

```
Dev Tools
```

**Fallback generik:**

```
Utilities
```

Jika form mengizinkan lebih dari satu kategori: pilih **Launchpads + Dev Tools** (dan Utilities bila slot ketiga tersedia). Jangan pilih **Smart Contract Audit** — kita memakai kontrak yang sudah diaudit, bukan menjual jasa audit, dan itu bisa jadi alasan penolakan.
